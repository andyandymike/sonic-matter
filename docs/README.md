# SonicMatter

Physics-driven, controllable Foley for games—without a cloud service, a large
generative model, or a high-end GPU.

SonicMatter is currently implementing a narrow Godot 4.6.1 Gate A slice for
deterministic, physics-driven 3D impact Foley. It is an experimental acceptance
harness, not a production release. Private working specifications and planning
notes are intentionally excluded from this site and from Git.
