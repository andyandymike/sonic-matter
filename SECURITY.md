# Security Policy

## Supported versions

SonicMatter has not released a supported version yet.

## Reporting a vulnerability

Please do not disclose security-sensitive details in a public issue. Use the
repository host's private vulnerability reporting feature when available, or
contact the maintainers privately through the account that publishes the
repository.

Useful reports include the affected revision, platform, reproduction steps,
impact, and any suggested mitigation. Never include real credentials, private
audio, or licensed source assets in a report.

## Security boundaries

The intended project is local-first. Network access, automatic downloads,
telemetry, and execution of untrusted DSP or model files are outside the
default trust boundary and require explicit design review.
