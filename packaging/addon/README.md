# SonicMatter addon 0.1.0-rc0

This archive is the no-audio Gate A RC0 addon for Godot 4.6.1 on Windows.

1. Extract the archive into the root of a compatible Godot project.
2. Enable **SonicMatter** under **Project Settings → Plugins**.
3. Follow `docs/getting-started.md` to create material resources, a route map,
   one shared emitter, and collision adapters/bindings.

The archive intentionally contains no impact recordings. Bring assets whose
game-distribution rights you can prove. No compiler, Python runtime, model,
cloud service, or GPU is required by a game using the addon.
